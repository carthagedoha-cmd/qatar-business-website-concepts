Website administration

Authorized editors sign in securely with GitHub using the free Pages CMS dashboard. No website password is stored here.

Sign in to website editor ↗
  1. Sign in with the GitHub account that owns this repository.
  2. On first use, install the Pages CMS GitHub App for qatar-business-website-concepts only.
  3. Open Panda Food Centre, Trim Time Salon, or Concept Garage in the editor.
  4. Update text, images, contact details or brand colours, then save.
  5. Changes are committed to GitHub and the live GitHub Pages previews update after publishing completes.

Only repository owners or collaborators granted write permission can change the sites. The Pages CMS app requires your one-time approval. Major layout redesigns require a code/template update rather than a content field change.
