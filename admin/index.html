Buyer-only website administration

Preview stage: No customer administrator is activated. The three demonstration websites remain in a shared preview repository owned by the designer. Buyers will never be granted access to this shared repository.

What happens after the QAR 5,000 purchase

  1. The selected buyer's website is copied into a separate repository dedicated exclusively to that business, with the buyer's own GitHub account as the owner.
  2. Only the purchased business's pages, content, images and configuration are included. Other customers' data, websites and previews are excluded.
  3. The buyer may choose a domain and hosting. GitHub Pages may be used for demonstration; production/commercial hosting and associated costs are agreed separately.
  4. The buyer authorizes the Pages CMS GitHub App for that repository only, and signs in securely using their own GitHub account.
  5. The buyer can edit English/Arabic text, photographs, services, offers and contact details, and publish updates. Structural layout redesigns may require professional support.
  6. After the handover is accepted, the seller's repository access is removed. No seller account or shared login remains on the buyer's website.

Important

This is an ownership and handover explanation, not an active login page. There is no buyer password to enter before a business accepts the offer, and buyer-only control cannot be established until that buyer provides an account for the transfer.
